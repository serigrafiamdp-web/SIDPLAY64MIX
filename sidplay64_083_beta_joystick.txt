This is a beta version, and the new added joystick controls are only experimental.
Rewrote some small routines to shorten the program. 
Removed R and N keys.

M       Mode select: Manual, Next or Random
S       Screen on/off. (reduce video chip noise).

Other than that the Keyboard version is the same as before.

If you select Joystick controls :

COMMODORE KEY:   FAST FORWARD
SPACEBAR:        LOAD DIRECTORY

FIRE BUTTON:     LOAD SID

Joystick control without firebutton pressed:


                 CURSOR UP
                    |
                    |
PREVIOUS SONG   ---- ---- NEXT SONG
                    |
                    |
                CURSOR DOWN

Joystick control with firebutton pressed:

First move and hold the stick in the desired direction, then press fire, then release fire button.



                JUMP UPWARDS
                    |
PREVIOUS DIRECTORY  |   RESTART SONG
                  \ | /
                   \|/
CLOCK DECREASE  ----*---- CLOCK INCREASE (SHUFFLE)
                   /|\
                  / | \
         SET MODE   |   PAUSE/CONTINUE SONG
                    |
                JUMP BOTTOM
